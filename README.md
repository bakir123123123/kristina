# Ocuvanje albanskog jezika i identiteta

Kompletan statički web sajt: HTML + CSS + vanilla JavaScript, bez frameworka i bez `npm`.

## Otvaranje

Otvorite `index.html` u web pregledaču. Sve datoteke ostavite u istom folderu.

## Struktura

- `index.html` — HTML dokument, sa obaveznim naslovom `Ocuvanje albanskog jezika i identiteta`.
- `style.css` — novi urednički/magazinski dizajn, responzivni stilovi.
- `main.js` — stranice, navigacija, mobilni meni, pretraga i prikaz cijelih članaka.
- `content.js` — sadržaj preuzet iz priloženog dokumenta, datumi su podaci.
- `media/` — logo i svih 30 slika izvornog dokumenta.

## Objavljivanje

Sve datoteke prenesite na statički web hosting (npr. Netlify, GitHub Pages ili klasičan hosting). Početna datoteka mora se zvati `index.html`.

Navigacija između članaka koristi `#` adrese, pa radi i kada se HTML direktno otvori iz foldera.

Logo Fonda vodi na https://www.fzm.me/.

Napomena: Urednički datumi dodijeljeni su u okviru perioda 20.09.2026–20.10.2026. i nijesu istorijski datumi opisivanih događaja.
